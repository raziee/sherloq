# راهنمای نصب و استفاده از Sherloq

این سند مراحل نصب، راه‌اندازی و کار با برنامه Sherloq را به‌صورت گام‌به‌گام توضیح می‌دهد.

## پیش‌نیازها

| مورد | نسخه / توضیح |
|------|--------------|
| سیستم‌عامل | Linux، macOS یا Windows |
| Python | **3.11** (الزامی) |
| ابزار مدیریت محیط | [uv](https://docs.astral.sh/uv/) (پیشنهادی) یا pip/virtualenv |
| فضای دیسک | چند گیگابایت (شامل وابستگی‌های TensorFlow و مدل‌ها) |
| RAM | حداقل ۸ گیگابایت (۱۶ گیگابایت برای ابزارهای AI توصیه می‌شود) |

---

## نصب و راه‌اندازی

### گام ۱ — دریافت کد منبع

مخزن را کلون کنید و به پوشه پروژه بروید:

```bash
git clone https://github.com/GuidoBartoli/sherloq.git
cd sherloq
```

### گام ۲ — ایجاد محیط مجازی

Sherloq به Python 3.11 نیاز دارد. ابزار `uv` روش پیشنهادی است چون روی Linux، macOS و Windows یکسان عمل می‌کند و در صورت نیاز Python را نصب می‌کند.

**نصب uv** — راهنمای رسمی: [docs.astral.sh/uv/getting-started/installation](https://docs.astral.sh/uv/getting-started/installation/)

```bash
# ایجاد محیط مجازی با Python 3.11
uv venv --python 3.11
```

فایل `.python-version` در ریشه مخزن وجود دارد؛ بنابراین دستورات بعدی `uv` به‌طور پیش‌فرض از Python 3.11 استفاده می‌کنند.

**جایگزین با virtualenv/pip:**

```bash
python3.11 -m venv .venv
source .venv/bin/activate   # Linux/macOS
# یا: .venv\Scripts\Activate.ps1   # Windows PowerShell
```

### گام ۳ — نصب وابستگی‌ها

از **ریشه مخزن** (پوشه `sherloq`) اجرا کنید:

```bash
uv pip install -r gui/requirements.txt
```

**وابستگی‌های اختیاری (ابزارهای AI):**

اگر قصد استفاده از TruFor یا سایر ابزارهای مبتنی بر PyTorch را دارید:

```bash
uv pip install -r gui/requirements_ai_solutions.txt
```

### گام ۴ — اجرای برنامه

#### Linux / macOS

```bash
source .venv/bin/activate
python -m gui.sherloq_app
```

#### Windows (PowerShell)

```powershell
.venv\Scripts\Activate.ps1
python -m gui.sherloq_app
```

#### راه‌انداز سازگاری (از ریشه مخزن)

```bash
python sherloq.py
```

## عیب‌یابی نصب

### خطای Qt روی Linux

اگر پیام زیر را دیدید:

```
qt.qpa.plugin: From 6.5.0, xcb-cursor0 or libxcb-cursor0 is needed...
Could not load the Qt platform plugin "xcb"
```

این بسته را نصب کنید:

```bash
sudo apt install -y libxcb-cursor-dev
```

### خطای import یا ماژول یافت نشد

- مطمئن شوید از **ریشه مخزن** (`sherloq/`) اجرا می‌کنید، نه از داخل `gui/`
- محیط مجازی فعال باشد
- وابستگی‌ها را دوباره نصب کنید:

```bash
uv pip install -r gui/requirements.txt
```

### ابزار TruFor کار نمی‌کند

- `gui/requirements_ai_solutions.txt` را نصب کنید
- پوشه `gui/TruFor_main` و وزن‌های مدل باید موجود باشند

## نحوه استفاده

### شروع کار

1. برنامه را اجرا کنید (گام ۴ بالا)
2. از منوی **File → Load image...** یا دکمه بارگذاری در نوار ابزار، یک تصویر باز کنید
3. پس از بارگذاری، پنل **TOOLS** در سمت چپ فعال می‌شود
4. ابزار مورد نظر را **دوبار کلیک** کنید تا در پنجره جدید باز شود
5. پنجره «تصویر اصلی» (Original Image) به‌طور خودکار باز می‌شود

### فرمت‌های پشتیبانی‌شده

JPEG، PNG، TIFF، BMP، WebP، PGM، PFM، GIF

### ساختار رابط کاربری

```
┌─────────────────────────────────────────────────────────┐
│  منو: File | View | Window | Help          [نوار ابزار] │
├──────────┬──────────────────────────────────────────────┤
│  TOOLS   │                                              │
│  (درخت   │     ناحیه MDI — پنجره‌های ابزار            │
│  ابزار)  │     (چند پنجره همزمان)                      │
│          │                                              │
├──────────┴──────────────────────────────────────────────┤
│  نوار وضعیت (پیام‌ها و وضعیت عملیات)                    │
└─────────────────────────────────────────────────────────┘
```

- **ناحیه مرکزی (MDI):** هر ابزار در یک زیرپنجره جداگانه باز می‌شود
- **پنل ابزارها:** دسته‌بندی‌ها شامل General، Metadata، Inspection، Detail، Colors، Noise، JPEG، Tampering، AI Solutions و Various
- **راهنمای ابزار:** نشانگر ماوس را روی نام ابزار نگه دارید تا توضیح کوتاه نمایش داده شود

### میانبرهای صفحه‌کلید

| میانبر | عملکرد |
|--------|--------|
| `Ctrl+O` | بارگذاری تصویر |
| `Tab` | نمایش/مخفی کردن پنل ابزارها |
| `F1` | راهنما (در حال توسعه) |
| `F10` | حالت تب‌دار / پنجره‌ای |
| `F11` | چیدمان کاشی‌ای پنجره‌ها |
| `F12` | چیدمان آبشاری پنجره‌ها |
| `Ctrl+F12` | بازگشت به نمای عادی از تمام‌صفحه |
| `Ctrl+Shift+W` | بستن همه پنجره‌های ابزار |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | پنجره بعدی / قبلی |
| `Ctrl+Q` | خروج |

### مدیریت پنجره‌ها

- **Tile (F11):** چیدمان غیرهم‌پوشان پنجره‌ها
- **Cascade (F12):** چیدمان هم‌پوشان
- **Tabbed (F10):** نمایش ابزارها به‌صورت تب
- **Close All:** بستن همه ابزارهای باز
- اگر همان ابزار دوباره انتخاب شود، پنجره موجود فعال می‌شود (تکراری باز نمی‌شود)

### فایل‌های اخیر

منوی **File** تا ۵ فایل اخیر را نگه می‌دارد. تنظیمات پنجره و فایل‌های اخیر بین اجراها ذخیره می‌شوند.

## گردش کار پیشنهادی برای تحلیل تصویر

یک رویکرد عملی برای بررسی اولیه تصویر مشکوک:

### ۱. بررسی کلی

1. **Original Image** — مشاهده تصویر بدون تغییر
2. **File Digest** — هش فایل و اطلاعات فیزیکی
3. **EXIF Full Dump** — متادیتا (دوربین، تاریخ، نرم‌افزار ویرایش)
4. **Thumbnail Analysis** — مقایسه thumbnail تعبیه‌شده با تصویر اصلی

### ۲. بازرسی بصری

1. **Enhancing Magnifier** — بزرگ‌نمایی با فیلترهای تقویت
2. **Channel Histogram** — بررسی توزیع رنگ
3. **Global Adjustments** — تنظیم روشنایی/کنتراست برای دیدن جزئیات پنهان
4. **Reference Comparison** — مقایسه با تصویر مرجع (در صورت وجود)

### ۳. تحلیل فشرده‌سازی (برای JPEG)

1. **Quality Estimation** — کیفیت آخرین ذخیره
2. **Error Level Analysis (ELA)** — نواحی با سطح فشرده‌سازی متفاوت
3. **JPEG Ghost Maps** — اثر سطوح مختلف فشرده‌سازی

### ۴. تحلیل نویز و جزئیات

1. **Signal Separation** — تفکیک نویز
2. **Bit Plane Values** — ناسازگاری در صفحات بیت
3. **Wavelet Blocking** — ناسازگاری نویز در بلوک‌ها
4. **Luminance Gradient** — تغییرات غیرطبیعی روشنایی

### ۵. تشخیص دستکاری

1. **Copy-Move Forgery** — نواحی کپی‌شده
2. **Composite Splicing** — نواحی الحاق
3. **Image Resampling** — اثر تغییر اندازه یا چرخش
4. **Contrast Enhancement** — تقویت کنتراست مصنوعی

### ۶. رویکرد هوش مصنوعی (اختیاری)

1. **TruFor** — نقشه احتمال جعل (نیاز به وابستگی‌های AI)

> هیچ ابزاری به‌تنهایی نتیجه قطعی نمی‌دهد. نتایج چند ابزار را با هم مقایسه کنید و در صورت امکان با تصویر مرجع یا دانش حوزه‌ای تفسیر کنید.

```

    ui/                     ویجت‌های Qt، نمایشگر، درخت ابزار
    tools/                  ابزارها بر اساس دسته‌بندی

  butteraugli/              ابزار Butteraugli

  TruFor_main/              TruFor (اختیاری)
```

## سؤالات متداول

**آیا Sherloq می‌تواند بگوید تصویر جعلی است؟**  
خیر. Sherloq ابزار آزمایش و آموزش است، نه داور نهایی. نتایج باید توسط متخصص تفسیر شوند.

**چرا برخی ابزارها کج (italic) هستند؟**  
این ابزارها هنوز پیاده‌سازی نشده‌اند.

**آیا به GPU نیاز دارم؟**  
برای بیشتر ابزارها خیر. ابزارهای AI (TruFor) با GPU سریع‌تر اجرا می‌شوند اما روی CPU هم کار می‌کنند.

**آیا می‌توانم ابزار جدید اضافه کنم؟**  
بله. هر ابزار یک ویجت Qt در `gui/sherloq_app/tools/` است و در `main.py` و `ui/tools.py` ثبت می‌شود.
